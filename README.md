# Vagbhata

Vagbhata wrote two famous classical texts on traditional Indian medicine: _Ashtanga Hridaya Samhita_ and _Ashtanga Sangraha_.

## Key Medical Texts
- **Ashtanga Hridaya Samhita**: A concise book containing 7,120 Sanskrit verses divided into 6 sections, summarizing the eight parts of Ayurveda for students. 

- **Ashtanga Sangraha**: A larger, more detailed prose-and-verse combination text covering similar foundational rules of health, diagnosis, and treatment.

This project focuses on _Ashtanga Hridaya Samhita_
